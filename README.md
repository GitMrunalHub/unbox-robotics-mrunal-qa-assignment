Objective

Automate the following flow using Selenium + Java + TestNG:
Open Flipkart
Close login popup
Search for "mobile"
Verify search result text
Add 10th and 11th phones to compare tray
Open 10th phone
Add product to cart
Increase quantity
Remove item from cart
Verify empty cart message

Tech Stack
Java
Selenium WebDriver
TestNG
Maven
Page Object Model (POM)
